
<h1>ClickArmor: Phishing URL Detection</h1><p>Welcome to <strong>ClickArmor</strong>, an innovative project designed to safeguard users from malicious phishing attempts by accurately identifying fraudulent URLs. In today's digital landscape, phishing attacks pose a significant threat, compromising sensitive information and user trust. ClickArmor leverages advanced machine learning techniques to analyze URLs in real-time, providing a quick and reliable assessment of whether a given URL is benign or a sophisticated phishing threat. This tool is built for security-conscious individuals, developers, and organizations looking for an intuitive and effective way to enhance their online security posture.</p><h2>✨ Features</h2><ul><li><strong>Intuitive Streamlit UI:</strong> A user-friendly web interface for effortless URL analysis.</li><li><strong>Real-time Phishing Detection:</strong> Instantly classify URLs as <strong>benign</strong> ✅ or <strong>phishing</strong> 🚨.</li><li><strong>Confidence Scores:</strong> Provides a probability score for each prediction, indicating the model's certainty.</li><li><strong>Custom Styling:</strong> Enhanced visual feedback with distinct styling for benign and phishing results.</li><li><strong>Robust Backend:</strong> Utilizes a powerful prediction pipeline for accurate and efficient analysis.</li></ul><h2>🚀 Installation</h2><h3>Prerequisites</h3><ul><li>Python 3.8+</li></ul><h3>Steps</h3><ol><li><strong>Clone the repository:</strong><pre><code>git clone https://github.com/sahilk5514/ClickArmor.git<br>cd ClickArmor</code></pre></li><li><strong>Create a virtual environment (recommended):</strong><pre><code>python -m venv venv<br>source venv/bin/activate  # On Windows: `venv\Scripts\activate`</code></pre></li><li><strong>Install dependencies:</strong><pre><code>pip install -r requirements.txt</code></pre></li></ol><h2>💡 Usage</h2><p>Once the dependencies are installed, you can run the Streamlit application locally and begin analyzing URLs.</p><ol><li><strong>Run the Streamlit application:</strong><pre><code>streamlit run app.py</code></pre><p>This command will open the ClickArmor application in your web browser, typically at <code>http://localhost:8501</code>.</p></li><li><strong>Enter a URL:</strong> In the web interface, enter the URL you wish to analyze into the provided text input field.</li><li><strong>Analyze URL:</strong> Click the "🔍 Analyze URL" button.</li><li><strong>View Prediction:</strong> The application will display whether the URL is predicted to be <strong>phishing</strong> 🚨 or <strong>benign</strong> ✅, along with a confidence score.</li></ol><h3>Example Prediction:</h3><p><em>Input:</em> <code>https://paypal-login-secure-update.com</code></p><p><em>Output (Phishing):</em></p><pre><code>🚨 Prediction: Phishing<br>Confidence: 0.9876</code></pre><p><em>Input:</em> <code>https://www.google.com</code></p><p><em>Output (Benign):</em></p><pre><code>✅ Prediction: Benign<br>Confidence: 0.9995</code></pre><h2>🛠️ Technologies Used</h2><ul><li><strong>Python:</strong> Primary programming language.</li><li><strong>Streamlit:</strong> For building the interactive web user interface.</li><li><strong>Scikit-learn:</strong> Machine learning library for model development.</li><li><strong>LightGBM:</strong> Gradient Boosting framework used for the prediction model.</li><li><strong>Pandas:</strong> Data manipulation and analysis.</li><li><strong>Numpy:</strong> Numerical computing.</li><li><strong>Dill:</strong> For serializing Python objects, Project dependencies<br>├── setup.py                   # Project setup file (for packaging, currently a placeholder)<br>└── src/<br>    └── pipeline/<br>        └── predict_pipeline.py    # Core <code>src/pipeline/predict_pipeline.py</code> to perform URL analysis.</p><h2>⚙️ Configuration</h2><p>ClickArmor is designed to be largely plug-and-play. The prediction model and its dependencies are loaded directly by the <code>PredictPipeline</code> class.
